# Helamin — журнал изменений

## Ветка `chore/stabilize`

Приведено в порядок перед клиентскими правками.

### Исправлено

- `UserFactory` и `config/auth.php` восстановлены после фильтрации истории Git:
  слово `password` было заменено маркером цензуры прямо в коде.
- `filament/filament` перенесён из `require-dev` в `require`, `composer.lock`
  переклассифицирован: `composer install --no-dev` больше не ломает админку.
- `User` реализует `FilamentUser::canAccessPanel()` — в не-local окружении
  панель доступна только пользователям с `is_admin = true`.
- `AdminMiddleware` берёт пользователя из `$request->user()`, а не из глобального `Auth`.
- `AdminUserSeeder` читает креды через `config()`, поэтому работает при `config:cache`.
- `deploy.sh`: единый путь `temp-laravel`, `filament:assets`, `storage:link`, права `775`.

### Архитектура

- Один источник контента — таблица `pages`. `PageSeeder` содержит 19 страниц,
  весь текст перенесён из статических Blade-шаблонов в Markdown и работает
  через `updateOrCreate`.
- Удалены 29 мёртвых Blade-шаблонов, `web_old.php`, `README_old.md`,
  `welcome.blade.php` и неиспользуемый Vite/Tailwind-контур.
- Удалены разделы «Отрасли промышленности» и «Референции» из роутов, меню и сидера.
- Добавлены реальные feature/unit-тесты вместо заглушек: `php artisan test` — 20 passed.

### Безопасность

- Контент рендерится через `Str::markdown` (`html_input => 'strip'`,
  `allow_unsafe_links => false`); сырой HTML больше не выводится через `{!! !!}`.
- CSP вынесен из `<meta>` в HTTP-заголовок, добавлены `X-Content-Type-Options`,
  `X-Frame-Options`, `Referrer-Policy`; админка/Livewire исключены.
- Убран внешний Google Fonts, используется системный шрифт.

### Админка для менеджеров

- Форма содержит только заголовок, Markdown-текст, meta description,
  картинки и PDF. Поля `slug`, `type`, `is_active`, создание и удаление страниц убраны.
- Массовая загрузка картинок (JPG/PNG/WebP/GIF/AVIF, без SVG) с изменением порядка.
- Массовая загрузка PDF в `storage/app/public/documents`; готовые Markdown-ссылки
  показываются в «Просмотре», список документов выводится на странице автоматически.
- Галерея и список документов оформлены в `public/css/media.css`.

### Дополнительно по просьбе клиента

- Вся документация перенесена в `docs/` (`README.md`, `DEPLOYMENT.md`,
  `CHANGELOG-admin.md`), ссылки внутри обновлены.
- `public/favicon.svg` — крупная красная буква H на вкладке браузера
  (нарисована геометрией, без зависимости от шрифтов), `favicon.ico` оставлен
  как fallback.
- Исправлено удаление прикреплённых PDF: убрано `preserveFilenames()`, имена
  теперь `slug + ULID` (уникальные, без пробелов), добавлены явные `deletable()`
  и `deleteUploadedFileUsing()`, удаляющий файл с диска.
- Исправлено экранирование: `Page::mediaUrl()` строит относительный
  `/storage/...` с `rawurlencode()` по сегментам. Это же починило невидимые
  картинки — раньше `Storage::url()` подставлял `APP_URL=http://localhost`.
- Картинки и PDF хранятся одинаково; в «Просмотре» теперь готовые Markdown-ссылки
  и для картинок (`![Описание](...)`), и для документов. Галерея оставлена —
  по ней удобно зрительно сравнить несколько загруженных картинок.
- Фон сайта можно менять из админки: поле «Фон сайта» в карточке главной
  страницы, плитка на `body`, полупрозрачный `.main-content`. Ручная замена —
  правило `body` в `public/css/media.css`.

### Исправлено после проверки в админке

- Удаление страниц было доступно через `DeleteAction` в шапке редактирования —
  главную страницу удалось удалить. Теперь `PageResource::canCreate()`,
  `canDelete()` и `canDeleteAny()` возвращают `false`, кнопка удаления убрана,
  а `Page::booted()` запрещает удалять главную даже из консоли. Главная
  восстановлена повторным запуском идемпотентного `PageSeeder`.
- Форма перевёрстана: `columns(['md' => 3])`, редактор текста занимает 2 колонки,
  остальные блоки собраны в `Group` в правой колонке и идут вертикально.
- Загрузка картинок «повисала» из-за `APP_URL=http://localhost`: Filament
  отдавал превью с чужого хоста. `config/filesystems.php` теперь использует
  относительный `/storage`, локальный `.env` и `.env.example` приведены к
  `http://127.0.0.1:8000`.
- Удаление прикреплённых PDF срывалось из-за колбэка со строгим типом `string`:
  Filament передаёт и строку, и `TemporaryUploadedFile`. Колбэк теперь
  обрабатывает оба варианта; кастомный генератор имён убран (штатные ULID-имена
  Filament безопасны и уникальны), добавлен `maxParallelUploads(1)` для
  устойчивой массовой загрузки.

### Уточнения по вёрстке

- Сетка формы не применялась: `columns(['md' => 3])` и `columnSpan(['md' => …])`
  не перезаписывали дефолтный `lg => 2`, поэтому текст растягивался на всю
  ширину, а «Картинки» вставали под ним. Заменено на `columns(3)`,
  `columnSpan(2)` у текста и `columns(1)->columnSpan(1)` у правой `Group` —
  теперь слева редактор на 2/3, справа вертикальный стек маленьких блоков.
  Проверяется тестом по реальному HTML (`--cols-lg`, `--col-span-lg`).
- Белая подложка `.main-content` скрывала фоновую картинку: осветлена с
  `rgba(255,255,255,0.86)` до `0.5`, добавлено лёгкое `backdrop-filter: blur(2px)`
  для читаемости текста. Полностью убрать подложку можно удалением одного
  правила в `public/css/media.css`.
