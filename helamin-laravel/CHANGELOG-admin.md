## Добавили

- `0001_01_01_000000_create_users_table.php` — модифицирована, добавлено поле `is_admin`
- `2026_10_01_094712_create_pages_table.php` — новая таблица для страниц с полями:

### Сидеры
- `AdminUserSeeder` — создаёт администратора (email: `helamin.admin@technology-holding.internal`, пароль: `%f9j6mJ2F20b03b`)
  - Учётные данные задаются через `.env` (`ADMIN_EMAIL`, `ADMIN_PASSWORD`) с fallback
- `PageSeeder` — заполняет таблицу pages базовым контентом

### Middleware
- `AdminMiddleware` — проверка, что пользователь является администратором (`is_admin = true`)

- `PageResource` — ресурс для управления страницами через админку
- `PageForm` — форма с WYSIWYG-редактором и выбором типа страницы
- `PagesTable` — таблица со списком страниц
- `PageInfolist` — просмотр страниц с форматированным контентом

### Маршруты
- `routes/web.php` — переписан для использования динамического роутинга через `PageController`

### Шаблоны
- `resources/views/pages/dynamic.blade.php` — универсальный шаблон для простых страниц
- `resources/views/pages/home_dynamic.blade.php` — шаблон для главной страницы с hero-блоком
- `resources/views/pages/oprosnyy-list.blade.php` — страница "Опросный лист"

## Особенности
- Админка скрыта: `/admin/login` доступен только по прямому URL
- На публичном сайте НЕТ кнопки "Войти"
- Учётные данные админа хранятся только в `.env` (никогда не коммитьте их в git!)
- Используется SQLite для локальной разработки
- Стандартная модель `User` Laravel для аутентификации
- Все страницы (кроме главной) используют единый шаблон с динамическим контентом
- Главная страница сохраняет hero-блок, а контент из БД выводится в основной части
